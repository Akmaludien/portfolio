# SKDQuest

> Flagship Project Documentation

## Executive Summary

SKDQuest is a gamified web platform designed to make SKD (Seleksi Kompetensi
Dasar) preparation more engaging, measurable, and motivating. Instead of
offering only question banks, the platform introduces progression, rewards,
analytics, and interactive learning experiences.

---

## Problem Statement

Many online learning platforms present practice questions in a static format,
making long-term preparation repetitive and reducing learner engagement.

The project aims to combine educational content with game design principles to
encourage consistent practice and measurable improvement.

---

## Objectives

- Improve student engagement.
