# Career Overview

My career has not followed a straight line or a checklist of technologies.

Instead, it has been driven by curiosity, real projects, and solving practical
problems.

Each stage naturally led to the next.

Instrumentation Engineering
→ Machine Learning
→ AI Applications
→ Software Engineering
→ Product Engineering
→ AI Software Engineering
→ Agentic AI

---

# Timeline

## 2022

Started studying Instrumentation Engineering at STMKG.

Built a foundation in mathematics, programming, statistics, networking,
measurement systems, and environmental technology.

---

## 2023

Developed stronger programming skills.

Began exploring data processing and machine learning concepts through academic
projects.

Started seeing software as a tool for solving engineering problems.

---

## 2024

Expanded practical experience through teaching.

Teaching mathematics, physics, SKD, and reasoning subjects strengthened:

- communication
- structured thinking
- problem decomposition
- explaining complex ideas clearly

These skills later proved valuable in software development.

---

## 2025

Internship (MBKM) introduced real operational systems involving weather
instrumentation, IoT, monitoring, and backend integration.

During the same period, research shifted heavily toward rainfall prediction
using Bidirectional LSTM.

This project became the turning point from academic machine learning into
building complete AI applications.

---

## 2026

Interest expanded beyond model development.

Focus moved toward:

- backend engineering
- deployment
- modern web applications
- AI-assisted workflows
- LLM integration
- AI agents

Projects such as SKDQuest reinforced an interest in product engineering and
building complete software rather than isolated components.
