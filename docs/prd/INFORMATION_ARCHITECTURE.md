# INFORMATION_ARCHITECTURE.md: Akmaludien's Premium Portfolio

## Overview

This document defines the information architecture for Akmaludien's Premium Portfolio, a single-page website designed to efficiently communicate his expertise and value proposition to target audiences. The structure prioritizes clarity, conciseness, and a logical flow of information to facilitate quick understanding and conversion.

## Site Structure

The portfolio is designed as a single-page application (SPA) with a linear, scrollable layout. Navigation is achieved through internal scroll-links within the page header, directing users to specific content sections.

### Navigation Links

*   Projects
*   Journey
*   Experience
*   Contact

## Page Flow

The content is organized in a top-down sequence, guiding the visitor through Akmaludien's profile, work, and professional journey.

1.  Hero
2.  Featured Projects
3.  Journey
4.  Experience
5.  Skills
6.  Contact
7.  Footer

## Content Hierarchy & Visual Priority

The visual emphasis and information density are strategically distributed to align with the objective of recruiter conversion within a short attention span.

1.  Hero (Immediate introduction and call to action)
2.  Featured Projects (Proof of capability)
3.  Call to Action (Implicit, via project links and resume download)
4.  Journey (Contextualizes experience)
5.  Experience (Detailed professional history)
6.  Skills (Technical capabilities)
7.  Contact (Engagement opportunity)
